MirrorDesk (tester build)
=========================

Mirror an iPhone, iPad or Android phone to a browser on this PC, with sound.

1. Double-click  Setup-MirrorDesk.cmd   (one time; needs the internet; Windows asks for permission once)
2. Read          TESTER-GUIDE.html      (how to connect each phone, what to try, how to report problems)

Afterwards start MirrorDesk from the Start menu or the desktop shortcut.
To remove it: Uninstall-MirrorDesk.cmd, then delete this folder.
INSTALL-GUIDE.html covers every way to install MirrorDesk (Windows, macOS, Linux, Docker/Dockge).
