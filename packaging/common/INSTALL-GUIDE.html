Install guide

MirrorDesk shows an iPhone, iPad or Android phone's screen and sound in a browser. It runs on one computer (Windows, Mac, Linux, or a server with Docker) and any browser on the same network can watch. Pick the install that matches that computer.

Windows __WINDOWS_FILE__

Needs
Windows 10 or 11, 64-bit Intel/AMD, internet once (about 200 MB)
Time
About 5 minutes
Installs into
The folder you unzip it to
  1. Right-click the zip → Extract All… → choose a short folder such as C:\MirrorDesk. Don't run it from inside the zip preview.
  2. In that folder, double-click Setup-MirrorDesk.cmd. If Windows SmartScreen says it protected your PC, click More info → Run anyway (the test build is not code-signed).
  3. When Windows asks "Do you want to allow this app to make changes?", choose Yes. That adds the firewall rules that let phones reach MirrorDesk.
  4. Your browser opens MirrorDesk. Next time, start it from the MirrorDesk shortcut in the Start menu or on the desktop.

Every day

  • MirrorDesk runs without a window. Its icon sits next to the clock (maybe under ^): Open MirrorDesk, Start with Windows, Quit MirrorDesk.
  • iPhone by cable: on the Devices page click Install cable driver once and allow the prompt.

Update

Quit MirrorDesk, extract the new zip into the same folder (replace the files), and run Setup-MirrorDesk.cmd again. Settings and codes are kept.

Uninstall

If you installed the iPhone cable driver, first open Devices → USB cable → restore Apple's driver. Then quit MirrorDesk, double-click Uninstall-MirrorDesk.cmd and delete the folder.

macOS __MACOS_FILE__

Needs
Apple Silicon with macOS 14 Sonoma or newer, or Intel with macOS 12 or newer; your Mac password; about 3 GB free
Time
10–30 minutes the first time, mostly downloads
Installs into
~/Library/Application Support/MirrorDesk and ~/Applications/MirrorDesk.app
  1. Double-click the zip in Downloads. You get a folder named MirrorDesk.
  2. Open Terminal (press ⌘ Space, type Terminal, press Return) and run: 
    sh ~/Downloads/MirrorDesk/install.sh
    If the folder is somewhere else, type sh and drag install.sh from Finder into the Terminal window, then press Return.
  3. If a window asks to install the Command Line Tools, click Install, wait until it finishes, then run the same command again.
  4. If the installer offers to install Homebrew, press Return and type your Mac password when asked (the letters don't show while you type). Homebrew provides GStreamer, which MirrorDesk uses for sound.
  5. The installer builds the AirPlay receiver (a few minutes), sets up Python, creates MirrorDesk.app and starts it. Your browser opens MirrorDesk.
  6. If macOS asks "Allow MirrorDesk to find devices on local networks?" or "accept incoming network connections?", choose Allow. Phones can't connect otherwise.

Prefer double-clicking? Install MirrorDesk.command in the folder does the same. Because the test build isn't signed, macOS may refuse to open it the first time. On macOS 15 or newer: open System Settings → Privacy & Security, scroll down, click Open Anyway. On macOS 14 and older: right-click the file → Open → Open.

Every day

  • Open MirrorDesk from Spotlight or from the Applications folder in your home folder (Finder → Go → Home → Applications).
  • While it runs, its icon is in the Dock. Click it to open the page; right-click → Quit stops MirrorDesk.
  • Settings → Start MirrorDesk when I log in to this Mac starts it at login, without a browser window.
  • On the iPhone, Screen Mirroring may also list your Mac itself (macOS has its own AirPlay Receiver). Choose MirrorDesk Web.
  • iPhone by USB cable doesn't work on a Mac, because macOS keeps the phone for itself. Use wireless, or QuickTime Player's own New Movie Recording on that Mac.

Update

Unzip the new version and run its install.sh the same way. It replaces the program and keeps your settings and codes.

Uninstall

Double-click Uninstall MirrorDesk.command, or run the following (add --purge to delete the settings too):

sh ~/Library/Application\ Support/MirrorDesk/mirrordesk-installer.sh --uninstall

Homebrew and its packages stay. Remove them separately if nothing else uses them.

Linux desktop __LINUX_FILE__

Needs
64-bit Linux (Intel/AMD or ARM) with apt (Debian, Ubuntu, Mint, Pop!_OS, Raspberry Pi OS), dnf (Fedora) or pacman (Arch, Manjaro); an account that can use sudo
Time
5–15 minutes
Installs into
~/.local/share/mirrordesk and the app menu
  1. Extract the zip: double-click it in your file manager and choose Extract, or run unzip __LINUX_FILE__. You get a folder named MirrorDesk with the program (app), install.sh and these guides.
  2. Open a terminal in the folder that contains MirrorDesk (usually Downloads) and run the installer as yourself, without sudo: 
    cd ~/Downloads
sh MirrorDesk/install.sh
  3. Type your password when sudo asks. It's needed for the system packages (GStreamer, build tools), USB access for phones, and firewall rules.
  4. If the installer asks Let usbmuxd share iPhones with MirrorDesk?, answer yes to use an iPhone by cable (only then does an iPhone's internet sharing by cable stop working on this computer).
  5. The installer builds the AirPlay receiver, sets up Python and Google's Android tools, adds MirrorDesk and Quit MirrorDesk to the app menu and opens MirrorDesk in your browser.

On a computer with a desktop the installer chooses this mode by itself. To force it, add --desktop.

Every day

  • Start MirrorDesk from the app menu. It runs in the background; opening it again just shows the page.
  • Quit: Quit MirrorDesk in the app menu, or Quit at the top right of the page.
  • In a terminal: mirrordesk start, mirrordesk stop, mirrordesk restart, mirrordesk status, mirrordesk log (open a new terminal after installing).
  • Settings → Start MirrorDesk when I log in.
  • If ufw or firewalld is on, the installer allowed MirrorDesk from home networks (10.x, 172.16–31.x, 192.168.x) and Tailscale (100.64.x).

Fedora: the iPhone's sound over AirPlay needs the AAC decoder from RPM Fusion. Enable RPM Fusion, install gstreamer1-plugin-libav, then run the installer again. The installer says so when the decoder is missing.

Update and uninstall

Update: extract the newer zip and run its install.sh the same way. Uninstall (add --purge to delete the settings too):

sh ~/.local/share/mirrordesk/mirrordesk-installer.sh --uninstall

Linux server over SSH one command

For a computer without a screen that you reach over SSH: a home server, a mini PC, a Raspberry Pi 4 or 5 with 64-bit Raspberry Pi OS. MirrorDesk then runs all the time as the service mirrordesk, and you use it from browsers on other devices.

Needs
Same Linux as above, SSH access, a user that can use sudo (or root)
Installs into
/opt/mirrordesk; settings in /var/lib/mirrordesk
Runs as
systemd service mirrordesk, user mirrordesk
  1. On your own computer, extract __LINUX_FILE__ (Windows: right-click → Extract All…). You get a folder named MirrorDesk.
  2. Open a terminal in the folder that contains MirrorDesk: Terminal on a Mac or Linux, Windows Terminal or PowerShell on Windows.
  3. Run this one line. It copies the folder to the server and runs the installer there. Replace USER@SERVER with your login and the server's address, for example pi@raspberrypi.local or ubuntu@192.168.1.40:
    macOS, Linux, Windows cmd, PowerShell 7
    scp -r MirrorDesk USER@SERVER:/tmp/ && ssh -t USER@SERVER sh /tmp/MirrorDesk/install.sh
    Windows PowerShell 5 (the built-in one)
    scp -r MirrorDesk USER@SERVER:/tmp/; ssh -t USER@SERVER sh /tmp/MirrorDesk/install.sh
  4. Type the SSH password (twice: copying, then logging in), then the sudo password when asked. The installer sets up everything and starts the service.
  5. At the end it prints the addresses to open, for example http://192.168.1.40:8765/, and the owner code. Open one in any browser on the network and enter the code. Give people who should only watch the viewer code from the Viewers page.

Already logged in on the server? Copy the zip there any way you like, then run unzip __LINUX_FILE__ and sh MirrorDesk/install.sh (if unzip is missing: sudo apt install unzip, sudo dnf install unzip or sudo pacman -S unzip). Without a desktop the installer picks the service mode by itself; --server forces it.

Options

AddWhat it does
--access-code MYCODE123Fixed viewer code (watch only, 6–32 letters/digits) instead of a random one
--port 8766Another web page port (default 8765)
--dockerInstall as a Docker stack instead (see Docker & Dockge)
--yesDon't ask questions, take the defaults
--helpList every option

Options go at the end of the command, for example ssh -t USER@SERVER sh /tmp/MirrorDesk/install.sh --access-code MYCODE123.

Manage the service

sudo systemctl status mirrordesk      # running?
sudo systemctl restart mirrordesk
sudo journalctl -u mirrordesk -f      # live log, shows the owner and viewer codes at start

Update and uninstall

Update: extract the newer zip and run the one-line command again from there. Settings, the codes and paired phones are kept. Uninstall (add --purge to delete the settings and the mirrordesk user too):

ssh -t USER@SERVER sudo sh /opt/mirrordesk/mirrordesk-installer.sh --uninstall

Docker & Dockge __COMPOSE_FILE__

Runs MirrorDesk in a container on any 64-bit Linux host with Docker: ZimaOS, CasaOS, Unraid, TrueNAS SCALE, Ubuntu Server and others. It uses the host's network directly (needed for AirPlay), so Docker Desktop on Windows or macOS can't run it.

Needs
Docker with the compose plugin, or Dockge
Time
A few minutes to download the image (B and C); 5–15 minutes when the installer builds it (A)
Image
__IMAGE__, downloaded from GitHub, or built on the host by the installer

A. One command (needs SSH access to the host)

The installer builds the image and creates the stack. When Dockge runs on the host, the stack goes into Dockge's stacks folder and shows up in Dockge as mirrordesk. Extract __LINUX_FILE__ on your computer, open a terminal in the folder that contains MirrorDesk, and run:

scp -r MirrorDesk USER@SERVER:/tmp/ && ssh -t USER@SERVER sh /tmp/MirrorDesk/install.sh --docker

Windows PowerShell 5: use ; instead of &&. To also use phones plugged into the server by USB, add --usb. At the end the installer prints the addresses and the owner code.

  • With Dockge: stack folder <Dockge stacks folder>/mirrordesk; data in its data folder.
  • ZimaOS / CasaOS without Dockge: stack in /DATA/AppData/mirrordesk-stack, data in /DATA/AppData/mirrordesk.
  • Other hosts without Dockge: stack and data in /opt/mirrordesk-docker.
  • If a mirrordesk stack already exists, the installer rebuilds the image and restarts that stack, keeping its compose file and data.

B. Paste the stack into Dockge (recommended)

  1. In Dockge click + Compose, name the stack mirrordesk, and paste the contents of __COMPOSE_FILE__ into the editor.
  2. Optional: in the .env box add settings from the table below, then click Deploy. Docker downloads the MirrorDesk image from GitHub by itself.
  3. Open the stack's log: the line Owner code (full control) has your code; Viewer code (watch only) is the one to give to people who should only watch.

C. Plain Docker Compose

Put __COMPOSE_FILE__ in a folder as compose.yaml and run:

docker compose up -d
docker compose logs mirrordesk     # owner/viewer codes and addresses

SettingDefaultMeaning
MIRRORDESK_DATA_DIR./dataWhere settings, keys and Android pairings are kept
MIRRORDESK_PORT8765Web page port
MIRRORDESK_ACCESS_CODErandomFixed viewer code (watch only), 6–32 letters/digits

Update and remove

Update: in Dockge, change the version at the end of the stack's image: line and click Deploy (B and C), or run the newer package's installer with --docker (A), which rebuilds the image and restarts the stack. Remove: delete the stack in Dockge, or run the following on the host. The stack folder and its data stay until you delete them.

sh /tmp/MirrorDesk/install.sh --docker --uninstall

Firewall on the host? Allow TCP 8765 (web page) and UDP 5353 (AirPlay discovery). In MirrorDesk's Settings → Advanced, set Fixed AirPlay ports to 7100, then allow TCP and UDP 7100–7102 too, and UDP 32768–60999 for the video to other devices.

After installing

  • On the computer itself: http://127.0.0.1:8765/ opens without a code.
  • Other devices: on the Viewers page copy the invitation link (or scan its QR code): it signs that device in to watch. Your own devices use the owner code (Settings → Access) for full control.
  • iPhone: Control Center → Screen Mirroring → MirrorDesk Web, then the 4-digit AirPlay code shown on the MirrorDesk page (a new one every time MirrorDesk starts).
  • Android: USB debugging by cable (Devices page → Android). Wireless debugging is there too, as a last resort.
  • Testing and reporting problems: see TESTER-GUIDE.html in the package.

If something doesn't work

The installer stopped with an error

Copy everything the terminal or setup window shows (from the first line) and send it to whoever gave you MirrorDesk. Running the installer again is safe: finished steps are skipped.

The iPhone doesn't list "MirrorDesk Web"
  • Phone and computer on the same Wi-Fi; no guest network or "client isolation".
  • Windows: the network must be Private (Settings → Network → your network). Run Setup again if you declined the Windows prompt.
  • macOS: System Settings → Privacy & Security → Local Network: turn MirrorDesk on.
  • Linux and Docker: a firewall must allow UDP 5353 and the AirPlay ports (see ports).
Another device can't open the page
  • Use an address from the Viewers page, including :8765.
  • Linux server: sudo systemctl status mirrordesk. Docker: docker logs mirrordesk.
  • Allow TCP 8765 in the computer's firewall.
Video works but there is no sound
  • iPhone over AirPlay on Fedora: install the AAC decoder from RPM Fusion (see Linux desktop).
  • Android: sound needs Android 11 or newer; on Android 11, unlock the phone before connecting.
An Android phone on USB is not found (Linux)

Unplug and plug it in again after installing (the USB permission rule applies to new connections), unlock the phone and tap Allow on "Allow USB debugging?".

iPhone by cable on Linux says usbmuxd keeps switching it back

Linux's usbmuxd (its iPhone service) decides the iPhone's USB mode. Run the installer again and answer yes to Let usbmuxd share iPhones with MirrorDesk?, then unplug the phone and plug it in again. Wi-Fi mirroring works without this.

Another device's browser says it blocks the video connection

Its privacy settings turned WebRTC off. Brave: Settings → Privacy and security → WebRTC IP handling policy → Default. Browser extensions that "prevent WebRTC leaks" do the same.
