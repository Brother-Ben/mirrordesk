Tester guide

Thank you for testing MirrorDesk. It shows a phone's screen and sound in a browser on this computer and on other devices of your network. Installing is covered in INSTALL-GUIDE.html; this guide is about using it and reporting what you find.

1Open MirrorDesk

  • Windows: the MirrorDesk shortcut (Start menu or desktop). Its icon sits next to the clock.
  • Mac: MirrorDesk in the Applications folder of your home folder, or Spotlight. Its icon is in the Dock while it runs.
  • Linux desktop: MirrorDesk in the app menu, or mirrordesk start in a terminal.
  • Linux server or Docker: it always runs; open the address the installer printed (for example http://192.168.1.40:8765/) and enter the owner code it printed.

2Connect a phone

The Mirror page shows the ways to connect while no phone is connected; the Phones page has the details, on an iPhone or iPad tab and an Android tab.

iPhone or iPad, Wi-Fi

  1. Phone and computer on the same network.
  2. Control Center → Screen Mirroring → MirrorDesk Web.
  3. Type the 4-digit code shown in MirrorDesk. The code stays the same while MirrorDesk runs, so a phone that stops mirroring can come back without it. MirrorDesk makes a new code and forgets every phone when it starts again, when you choose New code, or after 4 hours with no phone connected.

iPhone or iPad, USB cable

  1. Plug it in and unlock it.
  2. Windows only: Devices page → USB cable → Install cable driver → allow the prompt. Unplug and plug in again.
  3. On the phone tap Trust and enter the passcode.

Not available on a Mac. Linux: when the installer asks to let usbmuxd share iPhones with MirrorDesk, answer yes.

Android, USB cable

  1. Settings → About phone → tap Build number 7 times.
  2. Settings → System → Developer options → USB debugging on.
  3. Plug in, tap Allow on the phone (tick "Always allow").

Android, Wi-Fi (Android 11+) — last resort

  1. Developer options → Wireless debugging on.
  2. Devices page → Android → Wi-Fi (Wireless debugging) → Show QR code.
  3. Phone: Pair device with QR code and scan it (or use the pairing code fields).

Less secure than the cable: turn Wireless debugging off on the phone when you are done.

With an Android phone you can also use it from the computer: click and drag on the picture, scroll, type, and use the Back / Home / Apps buttons.

Disconnect (on the bar under the picture, or at the top of the Devices page) ends the phone's mirroring. A cable phone then waits until you unplug it and plug it in again, or click Reconnect.

Windows: the iPhone cable driver replaces Apple's driver for that phone, so iTunes / Apple Devices don't see it afterwards. To undo: Devices page → USB cable → "How cable mirroring works" → restore Apple's driver.

3What to try

  • Each connection type you can (Wi-Fi iPhone, cable iPhone, Android cable).
  • Portrait and landscape, a video or game with sound for 5–10 minutes. Is the sound smooth? Is it in step with the picture?
  • In a video: pause and play, skip forward and back a few times. Does the sound stay in step afterwards?
  • Lock and unlock the phone, unplug and plug the cable in again, switch apps.
  • On the iPhone: Control Center → Screen Mirroring → Stop Mirroring. The page should say so and go back to "Ready to mirror" right away.
  • Watch on another device: Viewers page → Copy the link and send it (or let the other device scan the QR code). Opening it signs that device in to watch only. Try it a few minutes after the phone started mirroring, too.
  • The Details button on the picture shows resolution, frame rate and a sound line (how much audio had to be filled in).

4Report a problem

  1. Open the Developer page (left side, under Testing).
  2. Right after something goes wrong, pick what happened (for example Sound problem) and click Mark issue. Do this every time; the time of each mark helps a lot.
  3. At the end click Export diagnostics. A file named MirrorDesk-diagnostics-….zip lands in your Downloads folder.
  4. Send that zip with a short note: which computer (Windows, Mac, Linux, Docker), phone model and system version, how it was connected, what you saw and roughly when.
  5. If an Android phone would not connect or stopped: also open Android log at the bottom of the Developer page, click Refresh, and paste that text into your message.
  6. If installing failed: copy the installer's messages instead (the whole terminal or setup window).

The diagnostics contain numbers and categories only (frame rates, buffer sizes, states, error categories). No video, no sound, no phone names, no addresses, no codes. Nothing is uploaded automatically; you can open the zip and check before sending.

5Stop MirrorDesk

  • Windows, Mac, Linux desktop: Quit at the bottom left of the page, in the browser on that computer. It asks first (tick Don't ask me again to skip that), then closes MirrorDesk completely, including its window.
  • Windows: icon next to the clock → Quit MirrorDesk. Mac: right-click MirrorDesk in the Dock → Quit.
  • Linux desktop: Quit MirrorDesk in the app menu, or mirrordesk stop in a terminal (mirrordesk start starts it again).
  • Linux server: sudo systemctl stop mirrordesk. Docker: stop the stack in Dockge or docker stop mirrordesk.

Removing MirrorDesk is described for each system in INSTALL-GUIDE.html.
