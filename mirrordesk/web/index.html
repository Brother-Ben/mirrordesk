How cable mirroring works
  1. Plug the iPhone into this computer and unlock it. The first time, tap Trust and enter the passcode.
  2. The screen appears here within a few seconds. No Wi-Fi or internet is used.
  3. While mirroring by cable, the phone's status bar shows 9:41 and a full battery. This is normal.
  4. If the picture does not start, unplug the phone and plug it in again. If that does not help, restart the phone.

Windows needs the cable driver (libusb-win32) for the phone. With the phone plugged in, click Install cable driver and allow the Windows prompt once. Afterwards iTunes and Apple Devices do not see this phone; to undo.

Turn on USB debugging (once per phone)
  1. Settings → About phone → tap Build number seven times (on some phones it is under Software information).
  2. Settings → System → Developer options → turn on USB debugging.
  3. Plug the phone into this computer, unlock it and tap Allow (tick "Always allow from this computer").
  4. Xiaomi, Redmi, POCO: also turn on USB debugging (Security settings) to control the phone from here.

Nothing is installed on the phone. Audio needs Android 11 or newer; on Android 11, unlock the phone before mirroring starts. Windows may need the phone maker's USB driver if the phone never shows "Allow USB debugging?".

Wi-Fi (Wireless debugging)

Wireless debugging lets a paired computer control the phone over the network. Use the cable when you can, pair only on networks you trust, and turn Wireless debugging off on the phone when you are done.

  1. Android 11 or newer: Settings → Developer options → Wireless debugging → turn it on.
  2. Tap Pair device with QR code and scan the code below, or tap Pair device with pairing code and enter what the phone shows here.

Valid for 2 minutes. The phone and this computer must be on the same Wi-Fi.

Pair uses the address, port and code from "Pair device with pairing code". After pairing the phone usually connects by itself; if not, enter the address and port shown at the top of the Wireless debugging screen and choose Connect.
